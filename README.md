# miko.ademagic.com
### My home on the internet.
[![Built with Astro](https://astro.badg.es/v2/built-with-astro/tiny.svg)](https://astro.build)

This is the repository for my personal website and blog, [miko.ademagic.com](https://miko.ademagic.com). It was built on [Astro](https://astro.build) using [Accessible Astro Starter](https://github.com/incluud/accessible-astro-starter).

For more (albeit brief) information on the tech I use on this site, check out my [Credits](https://miko.ademagic.com/credits) page.

## Getting started

| Command           | Action                                       |
| :---------------- | :------------------------------------------- |
| `npm install`     | Installs dependencies                        |
| `npm run dev`     | Starts local dev server at `localhost:4321`  |
| `npm run build`   | Build your production site to `./dist/`      |
| `npm run preview` | Preview your build locally, before deploying |
